# Linux server setup

The server setup now supports **Ubuntu, Debian, Fedora and Linux Mint**.

Use the [Linux hosting guide](../linux/README.md) and the [Linux server ZIP](https://github.com/misterlikyy/Homebrew_IDE/releases/download/latest/IDE-beta-collaboration-server-linux.zip).

The original Mint ZIP link and `setup-mint.sh` command remain compatibility shortcuts. There is no public online collaboration server operated by this project; the default setup is your own local-network server.
