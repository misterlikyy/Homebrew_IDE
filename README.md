# ide-alpha

Arduino Uno desktop IDE and dashboard.

## Download

- [Windows app (.exe)](downloads/ide-alpha-4.exe)
- [ZIP package](downloads/ide-alpha-4.zip)

## Build from source

Open the [source folder](source/) and double-click `build.bat`. It builds the Windows app and copies the EXE to your Desktop. Node.js is needed only to build.

The app source, dependencies list, example sketch, and build script are in `source/`. The ready-to-run downloads are kept separately in `downloads/`.
