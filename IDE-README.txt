UNO Bench for Arduino — Windows portable app

1. Extract IDE.exe from this ZIP.
2. Run IDE.exe and connect your Arduino Uno with a USB data cable.
3. Upload your sketch from this app. Auto pin readings is enabled by default for Uno uploads; the app adds the reporter to the upload copy and leaves the editor sketch unchanged.
4. The Dashboard shows text received from Serial.print/Serial.println as “Showing …”. Pin readings appear after the sketch has been uploaded from this app.

If you already have a sketch on the board, upload it once from this app to enable automatic pin readings.
