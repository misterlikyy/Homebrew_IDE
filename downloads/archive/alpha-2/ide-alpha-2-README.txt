ide-alpha — Alpha 2 (Windows portable)

Extract ide-alpha-2.exe from this ZIP and run it. It does not need an installer or Node.js.

Connect an Arduino Uno with a USB data cable. Auto pin readings can be enabled when you upload an Uno sketch from ide-alpha. The app adds pin reporting only to its temporary upload copy and leaves your editor sketch unchanged.

Alpha 2 fixes automatic pin reporting for normal sketches, clears old build errors when code changes, and restores the full Project canvas and Parts Library.
