ide-alpha — Alpha 1 (Windows portable)

Extract ide-alpha-1.exe from this ZIP and run it. It does not need an installer or Node.js.

Connect an Arduino Uno with a USB data cable. Auto pin readings are enabled by default when you upload an Uno sketch from ide-alpha. The app adds pin reporting to the upload copy and leaves the editor sketch unchanged. An existing sketch needs to be uploaded once from this app to start pin readings.

The Dashboard labels Serial Monitor text as “Showing …”.
